# breast-cancer-prediction-using-ANN

## Overview
This project focuses on detecting breast cancer using both Machine Learning models and Artificial Neural Network (ANN). The system classifies tumors as benign or malignant based on medical features.

## Objective
- Predict breast cancer using ML and ANN
- Compare different models
- Improve classification accuracy

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Dataset
Breast Cancer (Diagnostic) Dataset 
https://www.kaggle.com/datasets/uciml/breast-cancer-wisconsin-data

## Workflow
- Data Loading
- Feature Selection
- Data Preprocessing
- Label Encoding
- Train-Test Split
- Model Training
- Model Evaluation
- Visualization
- Model Saving

## Results
- Multiple models tested
- ANN shows strong performance
- Accuracy evaluated using test data

## How to Run
- Install required libraries
- Open the Jupyter Notebook
- Run breast_cancer.ipynb

## Applications
- Medical diagnosis support
- Early cancer detection
